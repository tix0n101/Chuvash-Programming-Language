# ЧăвашТĕп (ChavashTep) — Чăваш чĕлхиллĕ программировани чĕлхи

**ЧăвашТĕп** — ку хăйĕн синтаксисĕпе чуваш чĕлхине тĕпе хуракан çăмăл та ăнăçлă интерпретатор-программировани чĕлхи. Проект чăваш чĕлхипе программа кодне çырма, вĕсене тÿррĕн ăнланма тата компьютер çинче ĕçлеттерме май парать.

---

## 1. Синтаксис тата Тĕп Сăмахсем (Ключевые слова)

ЧăвашТĕп чĕлхинче çак тĕп сăмахсемпе усă курма пулать:

| Чăваш сăмахĕ | Пĕлтерĕшĕ / Аналоги | Тĕслĕх |
| :--- | :--- | :--- |
| **улшăнакан** | Переменная (`let` / `var`) | `улшăнакан х = 10;` |
| **кăлар** | Экрана кăларма (`print`) | `кăлар("Салам!");` |
| **эгер ... пулсан** | Условие (`if ... then`) | `эгер х > 5 пулсан { ... }` |
| **урăх** | Иначе (`else`) | `урăх { ... }` |
| **сехет** | Цикл (`while`) | `сехет х < 20 пулсан { ... }` |

---

## 2. Проект тытăму (Структура проекта)

Проект çак файлсенчен тăрады:
- `chuvash` (е `chuvash.py`) — тĕп хушăм (интерпретатор командăпа ĕçлет)
- `lexer.py` — лексер (чуваш текстне токенсене пайлать)
- `parser_ast.py` — синтаксис анализаторĕ (AST йывăçне тутарать)
- `interpreter.py` — интерпретатор (çав йывăçа тÿррĕн ĕçлеттерет)
- `test.cht` — чăваш чĕлхипе çырнă тĕслĕх код
